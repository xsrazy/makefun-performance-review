The funniest one-line performance review an AI agent could give its human operator, in 140 characters or fewer.

## Run it

```sh
python3 main.py
```

Running `main.py` writes the entry line to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The file contains exactly one line, with no trailing newline.
